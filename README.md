# API Testing with Playwright and Java

## Overview

A beginner-friendly API automation project created using **Playwright and Java**. The project demonstrates testing REST APIs using different HTTP methods, authentication, JSON request bodies, POJO classes, and response validation.

## Tools & Technologies

- Playwright
- Java
- TestNG
- Maven
- Jackson
- REST API
- IntelliJ IDEA
- Git & GitHub

## API Tests Covered

- **GET** - Retrieve user details and validate the response
- **POST** - Create a new user and validate the response
- **PUT** - Update user details and validate the response
- **DELETE** - Delete a user and validate the response
- Authentication and token generation
- Request header validation
- Query parameter validation
- Status code validation
- Response body validation
- JSON request and response handling
- JSON file-based request testing
- POJO-based API testing

## Booking API Tests

- Generate authentication token
- Create a new booking
- Capture the booking ID dynamically
- Update the created booking
- Delete the created booking
- Validate Create, Update and Delete responses
- Use authentication token for authorized requests
